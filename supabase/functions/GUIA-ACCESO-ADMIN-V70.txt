RC ORDERA v70 - CONFIGURAR ACCESO ADMINISTRATIVO

IMPORTANTE

La contrasena escrita en una conversacion debe considerarse expuesta.
No se guardo en la app. Cambiala y no vuelvas a publicarla.

ORDEN DE CONFIGURACION

1. En Supabase abre Authentication > Users.
2. Busca la cuenta administradora.
3. Confirma que la cuenta exista y que el correo aparezca confirmado.
4. En SQL Editor ejecuta primero:
   MIGRACION-FASE1-V67-VERIFICAR-ADMIN.sql
5. Revisa la fila final:
   - cuenta_auth = CUENTA_EXISTE
   - confirmacion = CORREO_CONFIRMADO
   - rol_administrador = ADMIN_ACTIVO
6. Ejecuta despues:
   MIGRACION-FASE1-V70-ACCESO-ADMIN-SEGURO.sql

CONFIGURAR ENLACES

En Supabase abre Authentication > URL Configuration.

Site URL:
https://rincon-colombiano-pedidosapp.vercel.app

Redirect URL:
https://rincon-colombiano-pedidosapp.vercel.app/admin.html**

CONFIGURAR CORREOS

El servidor de correo de prueba de Supabase solo envia normalmente a direcciones
autorizadas del equipo de la organizacion.

Usa una de estas opciones:

- Agrega la cuenta administradora como integrante de la organizacion de Supabase.
- Configura un proveedor SMTP propio en Authentication > SMTP Settings.

ACCESO

1. Publica la version v70.
2. Abre:
   https://rincon-colombiano-pedidosapp.vercel.app/admin.html
3. Para entrar con contrasena:
   - Escribe correo y contrasena.
   - Pulsa Iniciar sesion.
4. Para entrar sin contrasena:
   - Escribe el correo.
   - Pulsa Entrar sin contrasena.
   - Abre el enlace de un solo uso recibido.
5. Para instalar:
   - Pulsa Instalar panel.

No solicites enlaces desde admin.html abierto como file://. Supabase necesita una
direccion HTTPS autorizada para regresar al panel.

SEGURIDAD

- El correo autorizado no se muestra en admin.html ni admin.js.
- No existe una contrasena fija en el codigo.
- Una autenticacion valida sin platform_admin activo se cierra inmediatamente.
- La service_role nunca debe colocarse en el navegador.
